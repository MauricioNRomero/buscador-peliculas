# Buscador de Películas 🎬

App que consume la API de TMDB para buscar películas en tiempo real.

## Tecnologías
- HTML, CSS, JavaScript
- TMDB API
- BEM, CSS Grid, Flexbox, Responsive Design

## Demo
https://mauricionromero.github.io/buscador-peliculas

## Features
- Búsqueda en tiempo real
- Resultados con poster y título
- Búsqueda con Enter o botón
- Manejo de errores
- Diseño responsive mobile-first
